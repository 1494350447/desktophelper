设置与模型

文本模型（面试回答 / 文本解题）

推理模型（如 deepseek-flash、o 系列）会自动保证至少 4096 tokens，避免推理内容占满输出上限。

转写

麦克风与系统声音各自独立转写；默认麦克风=我，系统声音=对方。批量模式在停顿后上传 16kHz WAV；阿里百炼 HTTP 批量适合按句上传，识别后触发回答。DashScope 实时模式使用 16kHz PCM 持续上传，一句话结束后立即触发自动回答。

视觉

推理模型会自动保证至少 4096 tokens；仍被截断时应用会报错，而不是显示空答案。

题面提取

纯文本解题模型需要先由支持图片输入的提取模型读出题面。视觉模型可直接读图时可不配置。

推理模型会自动保证至少 4096 tokens；提取失败时会给出明确错误。

截图流程

触发与浮层

窗口默认点击穿透。点击顶部标题栏会激活整窗交互，按 Esc 或点击其他应用即可恢复穿透；拖动标题栏移动窗口，右下角可缩放。

界面默认单栏；点击标题栏右上的展开按钮可切换到双栏工作区，再点一次收回。

屏幕共享保护

Windows 10 2004+ 会把浮层从屏幕共享 / 录屏画面中移除；更旧的 Windows 版本会显示为黑块。 macOS 仅作兼容尝试，ScreenCaptureKit 仍可能捕获浮层。此功能只作用于浮层，不影响区域截图。

本地锁

本地锁只保护界面与数据展示，不涉及任何账号或服务端校验。

快捷键

点击输入框后直接按组合键即可录制；按 Esc、Backspace 或右侧 × 取消绑定。留空表示不注册全局快捷键。
